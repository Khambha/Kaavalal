# Official drought declaration labels

`drought_official_district_seasons.csv` records the district-season declarations found in Kerala government sources:

- 2016–17 Kharif and Rabi: all 14 districts were declared drought affected.
- 2017–18 Rabi: nine districts were declared drought affected based on IMD rainfall-deficit reporting and the State Drought Monitoring Cell assessment.

Sources: [KSDMA disaster notifications](https://sdma.kerala.gov.in/disaster-notifications/), [2017–18 Government Order](https://keralaagriculture.gov.in/wp-content/uploads/2019/01/go_and_circular/go_29032018_02.pdf), and [Kerala State Planning Board Economic Review](https://spb.kerala.gov.in/economic-review/ER2016/chapter02_02.php).

These are positive **district-season** labels. Districts absent from a declaration are unknown here, not verified negatives. These declarations cannot be copied to each constituency and treated as independent constituency outcomes. They are useful for checking whether a district-level seasonal drought indicator aligns with official declarations, but the small, positive-only set cannot establish model sensitivity, specificity, or general accuracy.
