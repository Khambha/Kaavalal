# KSDMA relief camp reference data

`Monsoon-Camp-Details-ALL-Kerala.xlsx` is a sanitized copy of the relief-camp
workbook linked from the [KSDMA Infrastructure Inventory](https://sdma.kerala.gov.in/infrastructure-inventory/)
(source file: `https://sdma.kerala.gov.in/wp-content/uploads/2020/08/Monsoon-Camp-Details-ALL-Kerala.xlsx`).

The source workbook contains an `Ownership` field with personal names and phone
numbers. That field and all other unneeded columns were removed before this file
was saved here. Only camp name, district, local body, village, source map point,
reported capacity, toilet/accessibility fields, and source type remain.

This is a static KSDMA inventory, not a live list of open camps or available
spaces. Verify current status with the district control room at 1077 before
travelling. The chatbot and citizen shelter directory must keep this distinction
visible and must not allow a request to be booked against a listed camp until an
administrator verifies and adds it as an operational shelter.
